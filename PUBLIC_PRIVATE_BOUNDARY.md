# Public and private boundary

## Safe for public release

- Fictional Maya support-lead scenario
- Fictional Northstar organization and account identifiers
- Synthetic policies and product documentation
- Synthetic evaluation cases
- Reference architecture and trade-off discussion
- Locally recorded model results after sanitization
- Rule-based pilot gates
- Static interactive site and social preview

## Never publish

- Employer information or internal terminology
- Real customer requirements, transcripts, or account data
- Production screenshots or architectures
- Credentials, API keys, environment files, or cloud project identifiers
- Raw service logs containing user or account information
- Unsupported claims that the reference design is production deployed

## Required public language

- Independent reference implementation
- Synthetic case and evidence
- Recorded model run when results are displayed
- Proposed production architecture when describing undeployed services
- No visitor-triggered model calls

## Pre-publication gate

- [ ] Recorded Gemini run completed
- [ ] Model and prompt configuration documented
- [ ] Failures reviewed and represented honestly
- [ ] Initial 15 cases expanded or justified before launch
- [ ] No credential or private-data patterns found
- [ ] Implemented and proposed architecture labels remain visible
- [ ] Social preview text and link verified
